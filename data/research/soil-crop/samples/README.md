# Farm soil sample

`farm-soil-report.pdf` is the original one-page Micro Tech Labs farm report supplied by the user for the sample review flow. The registered SHA-256 validates the unchanged file. It has six results; preserve printed analyte names, units, dates and the separate desirable-limits column. No values are preloaded or automatically confirmed.

The sample button creates a reference record, separate from farm measurements. A direct upload of this same report remains a field report so its owner can review and confirm their own measurements. The source is served through the authenticated report endpoints; there is no public source URL.

The previous ICAR sample PDF has been removed. Retired hashes remain in `retired-soil-reports.json` so old demo entries are hidden without deleting owners’ stored history. The ANACON PDF remains for the existing retirement regression fixture.
