# Footprint research data

`crop-footprint.json` (written by research, Packet A1; sources in `docs/research/FOOTPRINT_SOURCES.md`) holds the cited residue, energy and emission figures behind the Today view's residue income, energy footprint and carbon footprint blocks (`docs/research/TODAY_ECONOMICS_FOOTPRINT_SPEC.md` section 5). The API reads it only through `apps/api/src/services/today/footprint-data.ts`, a tolerant zod loader in the style of `services/year-plan/data.ts`: unknown fields are ignored; a malformed crop row (for example one without a `cropId`), constant, nested figure or list entry is skipped and recorded in `loadIssues()`; nothing is repaired, imputed or invented, and a missing value stays null (no cited figure, never zero). A range must have both bounds with `low <= high`, a share must lie in 0 to 1, and a second row for the same `cropId` is skipped. The parsed file is cached in module scope; `invalidate(fixture)` clears the cache and lets tests inject a raw object of the same shape. A missing file or a top level that is not an object of this shape throws, and the Today view then leaves the three blocks null with a limitation. The arithmetic on these figures is in `services/today/footprint.ts` (with its flagged `FOOTPRINT_ASSUMPTIONS`); the expected profit block does not read this file.
