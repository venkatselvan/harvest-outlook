# Speech evaluation cases

These reference text cases and the pure scoring helpers remain available for future Meta speech-recognition qualification. They do not themselves demonstrate accuracy on farmer recordings.

The former external-provider round-trip executable was removed. There is no active speech-synthesis integration and no external AI fallback. Historical result JSON is retained as audit history only; it does not describe current runtime capabilities.

Current dictation uses Meta Voice Transcribe with explicit consent and editable transcripts. See [the current speech contract](../../../docs/SPEECH.md). No synthetic fixture is returned as if it were a real transcription, and no language is marked field-qualified.
